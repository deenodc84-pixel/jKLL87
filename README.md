# Word Detective Bot

A Telegram bot that helps users discover the fascinating origins of words through etymology facts, word puzzles, and vocabulary building.

## Features
- 📖 Random word with origin and meaning
- 🧩 Word mystery puzzles
- 📅 Daily word of the day
- ⭐ Save favorite words
- 📊 Track learning progress

## Commands
- /start - Begin your journey
- /help - Get help
- /word - Random word with origin
- /puzzle - Word mystery puzzle
- /daily - Word of the day
- /favorite - Save or view favorites
- /mystats - View statistics
- /about - About the bot

## Deployment
Deploy on Railway with the included railway.json and Procfile.

## Requirements
- Python 3.8+
- python-telegram-bot==20.7
- python-dotenv==1.0.0
